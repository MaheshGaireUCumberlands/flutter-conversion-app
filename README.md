# Unit Conversion App

A Flutter application for converting between metric and imperial units for distance and weight.

## Features

- Convert distance: kilometers to miles and vice versa
- Convert weight: kilograms to pounds and vice versa
- Simple user interface with dropdown selection and input field

## Getting Started

### Prerequisites

- Flutter SDK installed
- Android/iOS setup

### Installation

1. Clone the repository
2. Run `flutter pub get` to install dependencies
3. Run `flutter run` to start the app on a connected device or emulator

## Usage

1. Select the conversion type from the dropdown
2. Enter the value to convert
3. Press the Convert button
4. View the converted value
